Majutsu is a Magit-style interface for [[https://github.com/jj-vcs/jj][Jujutsu (jj)]] in Emacs:
a log you can act on, diffs you can select from,
and menus for jj's commands.

Read the manual at [[https://majutsu.org][majutsu.org]], or its source in [[file:docs/majutsu.org][docs/majutsu.org]].

* Installation

#+begin_src emacs-lisp
;; Doom Emacs (packages.el)
(package! majutsu :recipe (:host github :repo "0WD0/majutsu"))

;; use-package + straight.el
(use-package majutsu
  :straight (:host github :repo "0WD0/majutsu"))

;; use-package + package-vc (Emacs 30+)
(use-package majutsu
  :vc (:url "https://github.com/0WD0/majutsu" :rev :newest))
#+end_src

* Usage

~M-x majutsu~ in a jj repository opens the log.

- ~n~ / ~p~ move between revisions (Evil: ~C-j~ / ~C-k~);
  ~[~ and ~]~ jump to a parent or a child.
- ~TAB~ folds the section at point.
- ~?~ lists every command.
- ~RET~ on a revision shows its diff; in a diff it visits the file.
- ~$~ (Evil: ~`~) shows what jj printed.

Commands open a menu in which you set options and pick revisions
from the log before anything runs.

| Vanilla | Evil    | Command                              |
|---------+---------+--------------------------------------|
| ~o~     | ~o~     | New change                           |
| ~c~     | ~c~     | Describe                             |
| ~w~     | ~i~     | Edit descriptions in place           |
| ~C~     | ~C~     | Commit                               |
| ~e~     | ~e~     | Edit a revision                      |
| ~k~     | ~x~     | Abandon                              |
| ~s~     | ~s~     | Squash                               |
| ~S~     | ~S~     | Split                                |
| ~a~     | ~a~     | Absorb                               |
| ~R~     | ~R~     | Restore                              |
| ~r~     | ~r~     | Rebase                               |
| ~V~     | ~_~     | Revert                               |
| ~? y~   | ~? y~   | Duplicate                            |
| ~d~     | ~d~     | Diff                                 |
| ~E~     | ~E~     | Ediff                                |
| ~? M~   | ~? M~   | Resolve conflicts                    |
| ~b~     | ~b~     | Bookmarks                            |
| ~? t~   | ~? t~   | Tags                                 |
| ~G~     | ~? G~   | Git: fetch, push, remotes, Gerrit    |
| ~Z~     | ~*~     | Workspaces                           |
| ~l~     | ~L~     | Log options                          |
| ~v~     | ~? v~   | Evolution log                        |
| ~X~     | ~X~     | Operation log, restore, revert       |
| ~C-/~   | ~u~     | Undo                                 |
| ~C-?~   | ~C-r~   | Redo                                 |
| ~!~     | ~!~     | Run a jj or shell command            |
| ~g~     | ~g r~   | Refresh                              |

In a diff, Split, Squash, Absorb, and Restore can take
selected hunks, files, or lines instead of the whole change.

* Integrations

All optional; see [[file:docs/majutsu.org::#integrations][Integrations]] in the manual.

- Evil :: Normal-state bindings are installed when Evil is present.
- Embark :: =embark-act= works on bookmarks, revisions, remotes,
  and workspaces.
- Forge :: ~(majutsu-forge-mode 1)~ shows pull requests and issues
  in the log of a colocated repository.
- Org :: ~org-store-link~ in a Majutsu buffer stores a link
  to a revision or a repository.
- TRAMP :: Repositories on remote hosts work.
- Ghostel :: Runs jj's terminal diff editor and =jj arrange= inside Emacs.
